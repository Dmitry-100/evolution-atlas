# Применение научной перепроверки — 14 сентября 2026

Ветка подготовки: `codex/factual-accuracy-cleanup`. Ниже зафиксированы изменения и результаты проверки перед публикацией. По запросу пользователя от 14 сентября изменения передаются в `main` для штатного CI/CD; фактический результат публикации фиксируется в GitHub Actions.

## Снятые материалы

Удалены пять PDF из `public/assets/materials`, их десять обложек, а также три версии постера `tree-of-life-poster`. Оригиналы остаются в истории Git. Снятие документа не означает, что каждое его утверждение признано неверным: это решение пользователя отказаться от материалов с недостаточной фактической надёжностью.

Убраны блоки презентаций и постера, ссылка со страницы вымираний, рекомендации PDF в экскурсиях и контекст ИИ-гида. Раздел материалов сохраняет книги, музеи и видео. Старые адреса `/materials/<файл>` ведут на актуальную страницу материалов. Процесс штатного деплоя удаляет отсутствующие файлы из хранилища и очищает CDN по адресам снятых PDF, обложек и всех версий постера.

Закрытые удалением записи: A23–A33, V01–V04, V06, включая их детальные подпункты. Научные вердикты в перепроверке сохранены.
