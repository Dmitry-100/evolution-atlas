# Острова эволюции — обновление интерфейса

Публичный адрес игры: https://atlas.aidms.ru/game. Локальная версия для разработки и просмотра: `http://127.0.0.1:4174/game`. Обновление публикуется вместе со статическим порталом через существующий workflow Yandex Object Storage.

## Что изменилось

- Вместо плоской карты — интерактивный архипелаг на Three.js: шесть объёмных островов, деревья, скалы, животные, вода, туман и эффекты погоды. Камеру можно вращать и приближать, возвращать к исходному ракурсу; анимацию можно остановить.
- Основной игровой ход помещается в экран: мир, текущая ситуация, четыре карты и кнопка следующего поколения видны одновременно. На телефоне камера перестраивает композицию в два столбца; в горизонтальном положении карты находятся справа от мира. Подробности острова, история, справка и настройка действия открываются в отдельных окнах с внутренней прокруткой при необходимости.
- Меню выбора и диалоги оформлены в тёмной зелёной палитре портала, с золотыми акцентами и заголовками с засечками. Выбор работает с клавиатуры; закрытие окна возвращает фокус к исходному элементу.
- Для восьми карт созданы отдельные иллюстрации. Изображения входят в сборку и используют версионирование ресурсов портала. Пути и точные запросы генерации сохранены в [манифесте иллюстраций](game-card-art-v2.json); готовые JPEG находятся в `public/assets/images/game/cards/`.
- Добавлены переходы карточек и окон, отклик выбранного острова и анимация смены поколений. Системная настройка уменьшения движения поддерживается.

## Технические границы

Игра остаётся полностью браузерной частью статического портала. Сохранения и правила первой версии совместимы; игровой сервер, база данных и внешние API не добавлены. После загрузки ресурсов партия работает без сети, но первое открытие страницы офлайн не обеспечивается.

3D-модуль загружается отдельно. Фоновая WebGL-анимация портала на игровой странице отключена, чтобы не создавать второй активный графический контекст. Частота обновления ограничена 30 кадрами/с, разрешение — DPR 1,5; на скрытой вкладке отрисовка приостанавливается, при уходе со страницы ресурсы освобождаются. При недоступном WebGL используется иллюстрированная карта с теми же игровыми действиями.

Животные в сцене представляют группы популяции. Это визуализация рассчитанного состояния, а не симуляция поведения каждого отдельного существа. Художественные иллюстрации показывают вымышленные экосистемы.

## Проверка

Прошли 177 модульных тестов, линтер, проверка совместимости CSS и сборка TypeScript/Vite. Сценарии Playwright проверяют полную партию из 18 ходов без сети, сохранение и восстановление, повреждённое и недоступное хранилище, управление клавиатурой, уменьшение движения, работу без WebGL, камеру и переходы между игрой и порталом.

Основной экран проверен при 1440×900, 1366×768, 1280×720, 390×844, 320×568 и 812×375: нет прокрутки страницы, все четыре карты и кнопка хода полностью доступны. Проверены раскрытые меню и диалоги. Это проверки в браузере с эмуляцией размеров; замеры производительности на физических телефонах ещё не проводились.

Повторить проверки:

```sh
corepack pnpm check
corepack pnpm e2e:game
```

Запустить локальный просмотр:

```sh
corepack pnpm dev --host 127.0.0.1 --port 4174 --strictPort
```
